# Routines — YouTube growth

Install after one full video cycle. Test runs = drafts only.

---

## YT Scout — twice weekly research

```
Create a routine: every Monday and Thursday at 9:00 AM America/Chicago, run skill "YT scout research run".
Deliver topic heat, competitor packaging notes, and Shorts patterns.
Hand off to Packaging and Scriptwriter. Do not publish or comment on videos.
```

## Packaging — per upcoming video (triggered)

```
When Growth Lead or Joseph names the next video topic, run skill "YT packaging pack".
Deliver titles, thumbnail concepts, and A/B plan. Do not change live metadata.
```

Or schedule a placeholder:

```
Create a routine: every Tuesday at 10:00 AM America/Chicago, check the War Room for the next approved topic.
If a topic is set and packaging is missing, run "YT packaging pack". If no topic, ping Growth Lead once and stop.
```

## Scriptwriter — after packaging locked

```
Create a routine: every Wednesday at 10:00 AM America/Chicago, if Packaging has an approved title direction for this week, run skill "YT script + shorts bridge".
Deliver hook, beats, Shorts bridges. Do not upload.
```

## YT Growth Lead — post-publish + weekly

```
Create a routine: every day at 6:00 PM America/Chicago, if a video was published in the last 72 hours, draft a 48–72h health note (CTR, early retention questions, what to test). Do not change titles/thumbnails without approval.

Create a routine: every Sunday at 4:00 PM America/Chicago, run skill "Weekly YT growth scoreboard".
Propose next week's calendar. No public actions.
```

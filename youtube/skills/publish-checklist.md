# Skill — YouTube publish approval checklist

Ask YT Growth Lead:

> Save as skill "YT publish approval checklist". Run before upload.

---

## Checklist

1. Channel promise fit?  
2. Title + thumbnail match the first 30 seconds?  
3. Hook written and timed?  
4. Oversell risk acceptable?  
5. Shorts bridge planned (or consciously skipped)?  
6. End screen / playlist path set?  
7. Ask: **Upload** / **Revise packaging** / **Revise script** / **Kill**

Return a short table. Wait.
